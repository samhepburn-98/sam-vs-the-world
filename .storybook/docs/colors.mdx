# Colors

Every color below renders from the **live CSS variables** in `src/styles.css`.
Ultimate is dark-only: the palette is defined once on `:root`, there is no
theme toggle, and there is deliberately no light variant — the atmosphere
gradients, earned gold, and baked card glows only work against near-black.

## Gold

<SwatchGrid>
  <Swatch token="--gold" note="The prestige accent" />
</SwatchGrid>

**Gold is earned** (rule 05). It marks traits, verdicts, hero scores, and the
VS badge — things the data awarded. It never decorates chrome, navigation, or
idle states, and it never encodes data.

## Status tokens

Jira-style semantic tokens, lifted to read on dark surfaces. Win/loss
colouring, trends, and callouts use these — never raw palette values. Warning
sits at hue 85, deliberately yellower than gold (hue 70), so caution never
masquerades as prestige.

## Chart ramp

A single-hue ember ramp, light to dark, for charts that need ordered steps of
one color (error breakdown, momentum). Player comparisons use `--primary` vs
`--p2` instead.

## The four gradients — the complete list

A gradient anywhere else — on a fill, a bar, a chart, text — is a bug
(rule 03). The atmosphere does the glowing so the data never has to. Each is a
Tailwind utility defined in `styles.css`.
