# Sam vs the World — design system

This Storybook is the living reference for the app's **Ultimate** design
system: stadium-at-night surfaces built around the FUT-style player cards.
Every reusable component gets a story here; the pages of the app are
compositions of what you see in the sidebar.

Everything renders from the **live CSS variables** in `src/styles.css`, so
these docs cannot drift from the app.

## The one-paragraph version

Ultimate is **dark-only** — near-black warm surfaces, one atmosphere gradient
per screen, ember for Sam and blue for the opponent, and gold reserved for
what the data awarded. Chakra Petch shouts the headings; Nunito Sans speaks
the sentences. The card is the brightest object on screen, and the data stays
flat so the atmosphere can glow.

The details live in the neighbouring pages:

- **Colors** — the palette, status tokens, chart ramp, and the only four
  gradients allowed to exist.
- **Typography** — the two voices and the heading primitives.
- **The ten rules** — what keeps this a design system instead of a costume.

## Where things go

- `src/components/ui` — shadcn primitives, themed by tokens only.
- `src/components` — shared composed components (typography, court, rally).
- `src/features/*` — feature-specific components; a feature never imports a
  sibling feature.
- Stories live next to their component as `*.stories.tsx`.

## Working rules

- **Semantic over raw.** Components reference tokens (`text-success`,
  `bg-p2`, `text-gold`), never one-off colours.
- **Headings are componentised.** `PageTitle`, `SectionTitle`, and `Overline`
  are the only way titles render.
- **Charts are recharts** wherever a chart type exists for the data; court
  visuals stay hand-drawn SVG.
- **Phone-first.** Every surface works at 390px with 44px hit targets before
  it earns a desktop layout.
